# Участие в проекте

Изменения рассматриваются как предложения; окончательное решение принимает владелец. Сохраняйте Kit маленьким: новая инструкция должна выражать полезное предпочтение, а не пересказывать обычную инженерную практику.

Перед передачей выполните `python scripts/check.py`, `git diff --check` и `git status --short`. Нужны Python 3.10+ и Git. Проверяющий скрипт не устанавливает зависимости и не обращается к сети. Прочитайте изменённые инструкции как пользователь; автоматическая проверка не оценивает их практическую пользу.

Коммиты: английский Conventional Commits с областью (`docs(kit): simplify instructions`), заголовок до 72 символов без точки в конце; тело при необходимости объясняет причину или несовместимость. Один коммит — один связный результат. Автоматический commit hook больше не поставляется.

Не включайте приватные пути, решения, отчёты и секреты в публичные файлы. О проблемах безопасности сообщайте по [политике безопасности](.github/SECURITY.md). Участие предполагает сохранение условий [MIT License](LICENSE).
