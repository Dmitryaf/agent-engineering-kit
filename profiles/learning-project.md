# Профиль: учебная разработка

## Назначение

Для проекта, где развитие самостоятельности владельца является устойчивой частью каждого этапа доставки, а не временной задачей одной сессии. Состав тематических правил определяется `sync/catalog.json` и manifest подключённого проекта.

## Уникальные обязательства

- У каждого сквозного этапа одна основная учебная цель.

Профиль не выбирается только ради разового изучения существующего проекта или создания учебного документа. Для такой задачи используется явный рабочий процесс `project-study` с проверкой самостоятельности; темп и предметные задания уточняются локально.

## Рекомендуемые локальные документы

Короткий процесс обучения, знания о проекте и временная сводка для продолжения, если они действительно поддерживаются.
