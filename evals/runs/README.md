# Результаты запусков

Для нового запуска скопируй `RESULT_TEMPLATE.json` в файл `<case-id>--<revision>--<run-id>.json`. Заполняй только наблюдаемые данные; неизвестное оставляй `null` или отмечай статусом `unknown`. Для задания, которое требует явного покрытия, перенеси опорный инвентарь в `inventoryResults`, а каждую существенную строку покрытия — в `coverageResults`; для остальных заданий используй пустые массивы.

Исход элемента инвентаря: `mapped`, `excluded` или `unknown`. У `mapped` должна быть ссылка на карту, у `excluded` — причина; `unknown` не считается подтверждённой полнотой карты.

Статус строки покрытия: `checked-no-finding`, `finding`, `not-applicable`, `unknown` или `not-checked`. Последние два статуса не являются успешной проверкой.

Перед добавлением результата в Git удали секреты, частные URL, локальные абсолютные пути, содержимое закрытых репозиториев и персональные данные. Сырые transcripts и tool logs остаются локальными, если у них нет явной публичной аудитории.

Результаты разных revisions сравнимы только при одинаковых task, fixture и существенных параметрах среды.
