# Результаты запусков

Для нового запуска скопируй `RESULT_TEMPLATE.json` в файл `<case-id>--<revision>--<run-id>.json`. Заполняй только наблюдаемые данные; неизвестное оставляй `null` или отмечай статусом `unknown`. Для задания, которое требует явного покрытия, перенеси каждую существенную строку в `coverageResults`; для остальных заданий используй пустой массив.

Статус строки покрытия: `checked-no-finding`, `finding`, `not-applicable`, `unknown` или `not-checked`. Последние два статуса не являются успешной проверкой.

Перед добавлением результата в Git удали секреты, частные URL, локальные абсолютные пути, содержимое закрытых репозиториев и персональные данные. Сырые transcripts и tool logs остаются локальными, если у них нет явной публичной аудитории.

Результаты разных revisions сравнимы только при одинаковых task, fixture и существенных параметрах среды.
