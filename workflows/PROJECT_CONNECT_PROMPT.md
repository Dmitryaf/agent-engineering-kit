# Подключение проекта

Используйте этот запрос в ИИ-агенте, открытом в корне подключаемого проекта. Путь к команде хаба уже указан в запросе.

## Готовый запрос

```text
Подключи этот проект к AI Rules Hub через {{HUB_CLI_PATH}}.

Действуй по шагам:
1. Проверь `git status`, локальные инструкции, основные точки входа, настройки и команды проверки. Сохрани несвязанные изменения владельца.
2. Выбери минимальный набор профилей и тем. Объясни выбор простыми словами и назови точные идентификаторы для `-Profiles` и `-Topics`. Не добавляй правило только потому, что оно есть в хабе.
3. Если `.ai-rules/manifest.json` отсутствует, выполни `connect -ProjectRoot "{{PROJECT_ROOT}}"` с выбранными `-Profiles` и `-Topics`. Если проект уже подключён, выполни эту команду без изменения состава правил.
4. Покажи созданные локальные файлы, предложенную версию хаба и файлы правил, которые будут добавлены или изменены. Отдельно скажи, что останется нетронутым.
5. Остановись перед `-Apply` и запроси одно явное разрешение на применение показанных изменений.
6. После разрешения повтори ту же команду с `-Apply`. Проверь результат командами `doctor` и `status`, затем покажи `git diff` проекта.

Не выходи за эти границы:
- не редактируй `.ai-rules/upstream/` вручную;
- не исправляй найденные разрывы проекта во время подключения;
- не выполняй `commit`, `push`, публикацию, удаление или изменение истории без отдельного разрешения;
- при существенной неоднозначности дай одну рекомендацию и задай один конкретный вопрос.

В конце кратко сообщи выбранный набор, созданные и обновлённые файлы, результат проверки, предупреждения и следующий отдельный шаг.
```
