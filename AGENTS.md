# Работа над Agent Engineering Kit

Репозиторий хранит короткие постоянные инструкции и инженерные Skills для Codex, а также минимальный пример проектного контекста. Продукт — Markdown; исполняемой установки и синхронизации нет.

Сохраняй эту простоту. Правило должно выражать устойчивое требование владельца или предотвращать конкретный существенный сбой, с понятной областью применения. Не восстанавливай каталог общих знаний, профили и собственную доставку правил. Локальные игнорируемые материалы не удаляй и не публикуй.

При изменениях проверь ссылки и образцы: `python scripts/check.py`, затем `git diff --check` и `git status --short`. Проверка требует Python 3.10+ и Git, использование Kit — нет.

Переход со старого механизма описан в [MIGRATION.md](MIGRATION.md); читай его при работе над совместимостью. Не изменяй подключённые проекты и глобальные настройки без отдельного запроса. Commit и push требуют явного разрешения; формат коммитов — английский Conventional Commits с областью, например `docs(kit): simplify instructions`.
